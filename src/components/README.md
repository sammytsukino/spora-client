# Componentes SPORA

Estructura production-ready por responsabilidad:

```
components/
├── ui/              Primitivos reutilizables (MainButton, PageTitle)
├── layout/          Estructura de página (navbars, footers, section, scroll)
├── shared/          Lógica compartida (rutas, modales, estados, FloraCardBase)
├── flora/           Dominio Flora (FloraCard, GreenhouseFloraCard, FeaturedFlora)
├── backgrounds/     Fondos animados (BubbleBackground)
├── home/            Secciones de Home (hero, marquee, video, auth forms)
├── laboratory/      Laboratory (Grainient, Lanyard, TextInput, LaboratoryNavbar)
├── profile/         Perfil de usuario
├── admin/           Panel de administración
└── team/            Vista Team
```
